(`schema.sql` 맨 끝에도 같은 내용이 들어 있습니다.)

  이벤트 선택(EV-*) 같은 본편이 아닌 값이 투표로 들어갑니다.
- `story_admin_repair_D.06.16.sql` — 다시 실행하면 관리자 코드 5회 잠금이 풀립니다.
- `security_patch_D.06.6.sql` — 다시 실행하면 접속 주소 판별이 예전(중계 서버 주소)으로 돌아갑니다.
