# 비령 세계관 개변 (`systems/biryeong`)

초록동색에서 가져온 아이템 · 상대 · 영능력을 비령(2046년, SF-조선 어반 오컬트)의 이름과 설명으로 바꾸는 표입니다.
수치(가격 · 효과 · 체력 · 공격력 …)는 그대로입니다. 보관고 원본은 고치지 않고, 실행 화면이 시작할 때 덮어씁니다.

| 파일 | 형식 |
|---|---|
| `items-a.txt` · `items-b.txt` | `id|새 이름|새 설명` — 아이템 312종 |
| `enemies.txt` | `id|새 이름|새 소개|영능력 1 이름|영능력 2 이름` — 상대 57종 |
| `psychics.txt` | `id|새 이름|새 설명` — 영능력 13종 |
| `pixel-templates.txt` | 12×12 도트 틀 37개 (`k` 외곽선 · `a` 바탕 · `b` 그늘 · `c` 빛 · `d` 포인트 · `.` 빈칸) |
| `build.mjs` | 위 파일들 → `reskin.data.js`. 아이템마다 도트 아이콘(틀 + 팔레트)을 정하는 규칙(`RULES`)과 화면 글자 치환(`TEXT_SWAPS`)도 여기 있다 |

이름을 고치려면 txt 를 고치고 `npm run build`. 아이템의 도트 아이콘을 바꾸려면 `build.mjs` 의 `RULES`(id 패턴 → 틀, 팔레트)를 고치거나 틀을 새로 그립니다.
게임 안에서는 `item.pixel = { t: 틀 이름, p: 팔레트 이름 }` 으로 붙습니다.
