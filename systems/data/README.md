# 비령 데이터 라이브러리 (독립 스냅샷)

`items.json`, `enemies.json`, `psychics.json`, `enemy-psychics.json` 및 제작·개척·스탯·효과 테이블은 초록동색 C.01에서 읽기 전용으로 복제한 데이터입니다.
이 폴더는 그 원본 서버와 무관하게 비령 프로젝트 안에서 독립적으로 관리합니다.
`index.mjs`는 `../rules/` 모듈만 참조하고, `build-catalogs.mjs`도 복사해 둔 비령 규칙을 사용합니다.
`catalog-manifest.json`의 `source`는 **역사적인 데이터 출처 표시**일 뿐 런타임 연결 주소가 아닙니다.

수집된 카탈로그: 아이템 312종, 적 57종, 영능력 13종, 적 영능력 슬롯 정의 69종, 개척 장소 23곳.
이 JSON만으로 전투 전체를 실행할 수는 없으며 동적 규칙은 `systems/rules/`를 사용합니다.
현재 브라우저 UI와는 연결하지 않았습니다.
